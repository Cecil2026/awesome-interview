# AI / 机器学习工程师面试路线图（8 周计划）

## 适合谁

有 2-5 年经验、正在转入（或想提升到）AI/ML 工程岗位的软件工程师——那种介于研究与生产之间的角色：构建 LLM 驱动的功能、RAG 流水线、模型服务基础设施和评测框架。你能流畅写代码、也交付过服务，但这类面试在标准 SWE 门槛之上加了第二条轴：应用 ML 基础、LLM/系统熟练度以及 ML 系统设计。这是一份起步路线图——一个可扩充的扎实骨架，而非详尽大纲。

## 时间投入

- 工作日：1.5-2 小时
- 周末：5-7 小时
- 合计：8 周约 90-110 小时

## 前置条件

- Python 熟练（能不查文档写类、生成器，并使用 `numpy`/`pandas`）
- 适应标准 SWE 算法门槛（数组、哈希、树、图）——本路线图不重教这些
- 基础线性代数与概率（向量、矩阵、点积、条件概率、期望）
- 至少从代码里调用过一个 ML 模型或 LLM API

## 这条流程考什么（也是本计划的目标）

1. **编码**——常规算法门槛，外加偶尔的数组/矩阵与数据处理题。
2. **ML 基础**——偏差/方差、过拟合、正则化、评估指标、常见模型的直觉。
3. **ML / LLM 系统设计**——"设计一个推荐系统"、"设计一个基于 RAG 的问答服务"、"如何在规模上服务并评测这个模型"。
4. **行为面**——主人翁意识、模糊性，以及你如何推理模型风险与失败。

## 计划

### 第 1 周：ML 基础复习

**重点：** 重建面试官前 10 分钟会探的词汇。

- [ ] 偏差-方差权衡、过拟合 vs 欠拟合，以及应对手段（正则化、更多数据、更简单模型、交叉验证）
- [ ] 有监督 vs 无监督 vs 自监督；分类 vs 回归
- [ ] 训练/验证/测试划分、数据泄漏，以及一个泄漏特征为何毁掉一切
- [ ] 阅读：梯度下降与学习率作用的简明复习

**里程碑：** 口头 3 分钟讲清偏差-方差，以及一种从学习曲线诊断过拟合的具体方法。

### 第 2 周：评估指标与模型直觉

**重点：** 指标是最常见的"你是否真懂 ML"过滤器。

- [ ] 精确率、召回率、F1、ROC-AUC、PR-AUC——以及各自何时是错误选择（类别不平衡！）
- [ ] 回归指标（MAE、RMSE、R²）及各自惩罚什么
- [ ] 逻辑回归、决策树、梯度提升、k-means 的直觉（非推导）
- [ ] 混淆矩阵推理：选与每类错误业务代价匹配的指标

**里程碑：** 给定 0.1% 正样本的欺诈检测场景，论证优化哪个指标、以及准确率为何是陷阱。

### 第 3 周：深度学习与 Transformer

**重点：** 足以推理现代模型的架构熟练度。

- [ ] 神经网络基础：层、激活、直觉层面的反向传播、梯度消失/爆炸
- [ ] 注意力机制与 transformer 块——自注意力计算什么、为何可扩展
- [ ] 嵌入：向量表示是什么、语义相似为何 ≈ 余弦距离
- [ ] 分词、上下文窗口，以及"参数量"到底算什么

**里程碑：** 5 分钟内向非 ML 工程师讲清自注意力，不糊弄 QKV 部分。

### 第 4 周：LLM 实战

**重点：** 大多数 AI 工程岗真正构建的应用层。

- [ ] 提示模式、少样本，以及结构化输出/函数调用在生产中为何重要
- [ ] 微调 vs RAG vs 提示——成本/延迟/新鲜度权衡与各自的取胜时机
- [ ] 幻觉：为何发生及缓解手段（接地、检索、验证、受约束解码）
- [ ] 温度、top-p 及其他解码旋钮

**里程碑：** 为三个场景决定微调 vs RAG vs 提示并为每个选择辩护。

### 第 5 周：检索增强生成（RAG）

**重点：** AI 工程师被问最多的单个系统设计话题。

- [ ] RAG 流水线：分块 → 嵌入 → 索引（向量库）→ 检索 → 重排 → 生成
- [ ] 分块策略，以及块大小/重叠为何改变答案质量
- [ ] 向量检索：近似最近邻（HNSW/IVF），以及混合（关键词 + 向量）检索
- [ ] 评估：检索质量（recall@k）vs 生成质量，以及为何两者都必须测

**里程碑：** 端到端白板一个基于 RAG 的内部文档问答系统，含你会如何评测它。

### 第 6 周：ML 系统设计

**重点：** 差异化轮次——设计 ML 系统，而不只是模型。

- [ ] 模板：需求 → 数据 → 特征 → 模型 → 服务 → 评估 → 监控
- [ ] 训练/服务偏差、特征存储、离线 vs 在线特征
- [ ] 批量 vs 实时推理；模型服务、批处理与延迟/吞吐权衡
- [ ] 监控：数据漂移、概念漂移，以及你如何知道线上模型已退化
- [ ] 练习：设计一个推荐系统和一个内容审核系统

**里程碑：** 做一次 45 分钟 ML 系统设计模拟，就结构与深度拿到反馈。

### 第 7 周：MLOps 与生产考量

**重点：** 证明你能上线并运维，而不只是做原型。

- [ ] 实验跟踪、模型版本化与可复现性
- [ ] 模型的 CI/CD、金丝雀/影子部署与回滚
- [ ] 对模型改动做 A/B 测试并诚实解读结果
- [ ] 成本：GPU 经济学、缓存 LLM 响应，以及何时更小的模型才是对的选择

**里程碑：** 勾勒你会如何安全地把新模型版本放量到 1% 流量并决定是否继续。

### 第 8 周：模拟流程与行为面

**重点：** 在面试条件下把一切整合起来。

- [ ] 2 场完整 ML 系统设计模拟（各 45 分钟），不同领域
- [ ] 1 场 ML 基础快问快答（指标、权衡、模型直觉）
- [ ] 准备 6-8 个 STAR 故事，含一个关于失败的模型/实验及所学
- [ ] 准备你对面试官关于其 ML 栈与评测文化的提问

**里程碑：** 干净的模拟流程——系统设计、基础轮、行为面——并写下自我反馈。
